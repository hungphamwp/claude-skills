## Vietnamese Market Queries

### Template: Vietnamese company websites
```
"công ty [ngành]" website "uy tín" -template -mẫu -thiết kế web
"[ngành]" site:.vn "wp-content" (catches WordPress sites)
top "công ty [ngành]" Việt Nam 2024 2025
"nhà thầu [ngành]" website chuyên nghiệp
```

### Why exclude certain terms
- `-template -mẫu -thiết kế web` → filters out web design agencies selling templates
- Adding `"wp-content"` → specifically finds WordPress sites
- Adding `site:.vn` → limits to Vietnamese domains

## International Queries

### Template: WordPress sites in specific industry
```
"[industry] company website" WordPress design 2025
best [industry] websites examples modern
"[industry]" company website professional portfolio
[industry] website "powered by WordPress"
```

### Template: Mid-size companies (avoid custom-coded giants)
```
"[industry] company" website -"fortune 500" -"top 10" modern professional
mid-size [industry] company website design examples
[industry] contractor website professional 2025
```

## Find-Similar Queries

When user says "find me websites similar to X":

### Step 1: Analyze the reference URL
Extract: industry, color scheme, layout pattern, company size

### Step 2: Search for similar
```
"[same industry]" website "[similar color word]" "[similar layout word]"
"[same industry]" company website "similar to" OR "like" [reference company]
competitors of [reference company] website
```

### Step 3: Visual similarity search
```
"[industry]" website "[dominant color]" minimalist/modern/corporate
"[industry]" website design "[layout pattern]" examples
```

## Search Result Filtering Tips

### Prioritize results from:
- Company websites directly (not design agency portfolios)
- "Top X companies in [industry]" lists (then visit each company's actual website)
- Industry association member directories
- Business directories with website links

### Avoid results from:
- ThemeForest / template marketplaces (these are themes, not real company websites)
- Web design agency showcases (biased toward their own complex work)
- "Best website design" lists (often feature custom-coded showpieces)
- Dribbble / Behance (concepts, not real functional websites)
