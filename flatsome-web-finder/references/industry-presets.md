# Industry Presets — Smart Defaults

When user only says the industry name with minimal details, use these presets to fill in sensible defaults automatically. This enables Quick Find mode to work well even with very short input.

---

## How to use

If user says "tìm mẫu web ngành xây dựng" — look up "Construction" below and auto-apply:
- Default company scale, B2B/B2C, style, must-have sections
- Search queries optimized for that industry
- Recommended color palettes
- Social proof elements typical for the industry

Only ASK the user about things that differ significantly within the industry.

---

## Construction / Xây dựng

**Defaults:**
- Scale: Mid-size to Large
- Audience: B2B
- Style: Corporate professional
- WooCommerce: Catalog (vật liệu) or None (chỉ dịch vụ)
- Region: Vietnam priority

**Must-have sections:**
- Hero: Project imagery slider or video
- About: Company history, values, milestones
- Services: Icon box grid (3-6 services)
- Projects/Portfolio: Filterable grid with categories (dân dụng, công nghiệp, thương mại)
- Statistics: Counter (năm kinh nghiệm, số dự án, nhân sự, khách hàng)
- Clients/Partners: Logo carousel
- News/Blog: Latest articles grid
- Contact: Form + map + phone

**Social proof:** Counter numbers, partner logos, certifications (ISO, OHSAS), awards

**Recommended colors:**
- Navy/dark blue + white + accent (orange or green)
- Dark grey + white + blue accent
- Avoid: bright/playful colors

**Typical fonts:** Roboto, Open Sans, Montserrat (heading), Be Vietnam Pro (VN sites)

**Search queries:**
```
VN: "công ty xây dựng" OR "nhà thầu" website "wp-content" site:.vn
VN: "tổng thầu xây dựng" website chuyên nghiệp
EN: construction company website WordPress modern
EN: general contractor website design professional
```
